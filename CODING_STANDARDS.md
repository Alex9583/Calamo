# Coding standards

One rule per file under [`docs/standards/`](docs/standards/). Load a file
only when the work touches its scope; each is a review axis for
`/code-review`.

- [Comments](docs/standards/comments.md) — writing or reviewing any comment
  (code, doc comments, headers, CI, config, scripts).
- [Small logical units](docs/standards/small-units.md) — a file or function
  grows, or section separators appear.
- [Given/When/Then tests](docs/standards/tests.md) — writing or reviewing
  behavioral tests, in Rust or Swift.

New rule → new file here, one scope per file, indexed above.
