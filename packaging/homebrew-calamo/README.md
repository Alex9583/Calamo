# Calamo Homebrew tap

Local-only, multilingual voice dictation for macOS — hold a hotkey,
speak, release.

```sh
brew tap alex9583/calamo
brew install --cask calamo
```

Calamo is not notarized by Apple: the install prints the first-launch
steps. Full story, model licences and attribution:
[Alex9583/Calamo](https://github.com/Alex9583/Calamo) —
[docs/distribution.md](https://github.com/Alex9583/Calamo/blob/master/docs/distribution.md).
